数据库技术学习指南

深入学习关系型数据库和NoSQL数据库，掌握SQL优化和数据库设计

MySQL

最流行的开源关系型数据库，掌握索引优化、事务处理、主从复制等核心技术

  • 索引原理与优化
  • 事务隔离级别
  • SQL 调优实战

Oracle

企业级数据库管理系统，学习PL/SQL编程、数据库管理和性能优化

  • PL/SQL 编程
  • 存储过程与触发器
  • 数据库备份恢复

Redis

高性能键值存储数据库，掌握数据结构、缓存策略、持久化机制

  • 五种基本数据类型
  • 缓存穿透/击穿/雪崩
  • 主从复制与哨兵

MongoDB

面向文档的NoSQL数据库，学习文档模型、聚合查询、分片集群

  • 文档模型设计
  • 聚合管道
  • 索引与性能优化

SQL优化

深入理解SQL执行计划，掌握查询优化技巧和索引设计原则

  • 执行计划分析
  • 索引设计策略
  • 慢查询优化

数据库设计

学习数据库设计范式、ER建模、表结构设计和数据迁移

  • 三大范式
  • ER 图设计
  • 分库分表策略
